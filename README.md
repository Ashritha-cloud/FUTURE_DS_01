# FUTURE_DS_01

## Business Sales Performance Analytics – Future Interns Task 1

### Project Overview

This project focuses on analyzing business sales data to understand sales performance, revenue trends, top-selling products, category performance, and regional performance.

The analysis was completed using Power BI to create an interactive dashboard and generate useful business insights.

### Objectives

- Analyze sales trends over time
- Identify top-selling products
- Compare sales across product categories
- Analyze regional sales performance
- Compare profit across categories
- Provide business insights and recommendations

### Tools Used

- Power BI
- Microsoft Excel / CSV
- Power Query

### Key Insights

- Technology generated the highest overall sales.
- The West region recorded the highest sales.
- Sales increased over the period, with the highest sales recorded in 2017.
- Phones and Chairs were the top-selling sub-categories.
- Technology generated the highest overall profit.

### Recommendations

- Focus on high-performing Technology products to support further sales growth.
- Study the successful performance of the West region and apply suitable strategies to other regions.
- Promote strong-performing sub-categories such as Phones and Chairs.
- Review Furniture performance to identify opportunities to improve profitability.

### Dashboard

The Power BI dashboard provides an interactive view of sales, profit, categories, regions, sub-categories, top products, and sales trends.
